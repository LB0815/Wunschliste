# Wunschliste

Eine responsive, interaktive Wunschlisten-Seite mit den Einträgen aus `Wunschliste.ods`.

## Starten

`index.html` direkt im Browser öffnen. Suche, Kategorien, Wichtigkeits-Sortierung und Merkliste funktionieren ohne Server; gemerkte Wünsche bleiben im lokalen Browser gespeichert.

Die Sterne zeigen die Wichtigkeit aus der Tabelle. In der ODS-Datei sind keine Preise eingetragen, deshalb zeigt die Seite `— €` und markiert den Preis als offen, statt Beträge zu erfinden. Die Produktnamen führen zu den jeweiligen Händlerlinks aus der Tabelle.
