# Wunschliste

Eine responsive, interaktive Wunschlisten-Seite mit den Einträgen aus `Wunschliste.ods`.

## Starten

`index.html` direkt im Browser öffnen. Suche, Kategorien, Wichtigkeits-Sortierung und Merkliste funktionieren ohne Server; gemerkte Wünsche bleiben im lokalen Browser gespeichert.

Die Preise und Sterne werden aus der ODS-Tabelle übernommen. Preise sind mit deutschem Zahlenformat dargestellt; Händlerpreise können sich ändern. Ein Klick auf eine Wunschkarte oder den Produktnamen öffnet den zugehörigen Händlerlink aus der Tabelle.
